## 2025-09-21 22:00 - 修复项目启动问题

### 问题描述
项目在从 `cmd` 目录运行 `go run main.go run` 时出现以下错误：
```
2025/09/21 21:55:20 加载模型文件失败: open conf\model.conf: The system cannot find the path specified.
2025/09/21 21:55:20 Casbin enforcer 初始化失败
exit status 1
```

### 问题分析
1. 当从 `cmd` 目录运行时，程序工作目录是 `cmd`，但配置文件在项目根目录的 `conf` 文件夹中
2. 代码中使用相对路径 `"conf"` 查找配置文件，导致路径错误
3. `server_judge.go` 中硬编码了配置文件路径 `"conf/config.yaml"`，同样存在路径问题

### 修复方案

#### 1. 修复 `cmd/main.go` 中的 Casbin 配置路径问题
- 添加智能路径检测，支持从 `cmd` 目录或项目根目录运行
- 修改代码：
```go
// 获取配置目录路径，支持从cmd目录或项目根目录运行
configDir := "conf"
if _, err := os.Stat(configDir); os.IsNotExist(err) {
    // 如果当前目录没有conf，尝试上级目录
    configDir = "../conf"
}
```

#### 2. 修复 `pkg/app/api-server/server/server_judge.go` 中的配置文件路径问题
- 添加路径检测和错误处理
- 添加必要的导入：`"log"` 和 `"os"`
- 修改 `NewJudge()` 函数：
```go
configPath := "conf/config.yaml"
if _, err := os.Stat(configPath); os.IsNotExist(err) {
    // 如果当前目录没有conf，尝试上级目录
    configPath = "../conf/config.yaml"
}

cfg, err := utils.LoadConfig(configPath)
if err != nil {
    log.Printf("加载配置文件失败: %v", err)
    // 返回默认配置的Judge
    return &Judge{
        choice: utils.LocalJudge,
        svc:    service.NewService(),
    }
}
```

#### 3. 修复运行命令
- 原来只运行 `go run main.go run` 只编译了 `main.go`，没有包含 `runServer.go`
- 正确的运行命令：`go run main.go runServer.go run`

## 2025-09-21 22:15 - 修复MongoDB认证问题

### 问题描述
项目运行时出现MongoDB认证错误：
```
timestamp="2025-09-21T22:13:48Z" level=error msg="MongoFindErr{error 26 0  (Unauthorized) Command find requires authentication} {table 15 0 submits <nil>} {query 23 0  map[status:1 stime:map[$gt:0]]}"
```

### 问题分析
1. MongoDB服务器(42.194.245.236:27017)启用了认证
2. 当前配置文件中只有基本的连接URI，没有包含用户名和密码
3. 需要在连接字符串中添加认证信息

### 修复方案

#### 1. 扩展MongoDB配置结构
- 修改 `pkg/utils/yaml.go` 中的 `MongoConfig` 结构体：
```go
type MongoConfig struct {
    Uri      string `yaml:"Uri"`
    DbName   string `yaml:"DbName"`
    Username string `yaml:"Username"`
    Password string `yaml:"Password"`
    AuthDB   string `yaml:"AuthDB"` // 认证数据库，默认为admin
}
```

- 同步更新 `conf/config.go` 中的配置结构

#### 2. 添加MongoDB URI构建函数
- 在 `pkg/utils/mongo.go` 中添加 `BuildMongoURI` 函数
- 支持自动构建带认证的MongoDB连接字符串
- 处理URL编码和认证数据库设置

#### 3. 更新DAO层连接逻辑
- 修改 `pkg/dao/dao.go` 中的 `NewDao()` 函数
- 使用新的URI构建函数创建MongoDB连接

#### 4. 更新配置文件
- 在 `conf/config.yaml` 中添加MongoDB认证配置项：
```yaml
Mongo:
  Uri: mongodb://42.194.245.236:27017
  DbName: zkoj
  Username: ""  # MongoDB用户名，如果需要认证请填写
  Password: ""  # MongoDB密码，如果需要认证请填写
  AuthDB: "admin"  # 认证数据库，默认为admin
```

### 使用说明
1. **无认证环境**：保持 `Username` 和 `Password` 为空，系统会使用原始URI
2. **需要认证环境**：填写正确的用户名和密码，系统会自动构建认证URI
3. **自定义认证数据库**：可以修改 `AuthDB` 字段指定认证数据库

### 下一步操作
需要联系MongoDB管理员获取正确的用户名和密码，然后更新配置文件中的认证信息。

func (m *Manager) loadAPIKeysFromEnv() error {
